# Mission 1 — Know your computer

## 1. Task / objective
Explain how a computer receives input, processes information, produces output and stores results (IPOS); identify hardware and software; and recognise computer-based systems in everyday life.

## 2. Work completed
- Task 1.1 — traced one activity (typing and saving a document) through IPOS.
- Task 1.2 — classified four hardware items and four software items.
- Task 1.3 — listed three everyday computer-based systems.

### Task 1.1 — IPOS trace: typing a document and saving it

| Stage | What happens in my example | Hardware / component |
|---|---|---|
| Input | I press keys; each keypress is sent to the computer as data | Keyboard |
| Processing | The CPU runs the text editor, which converts my keypresses into characters and keeps the draft in memory | CPU / processor and RAM |
| Output | The characters appear on screen as I type | Display |
| Storage | When I press save, the file is written to my SSD so it survives after the program closes | SSD (internal storage) |

The activity moves from input to output continuously (each keypress is processed and shown immediately), and only becomes permanent at the storage stage when I deliberately save the file.

## 4. My understanding
IPOS is not four separate events but a cycle that repeats for every action. Input and output are the boundary between me and the machine, processing is where the CPU turns raw data into meaning, and storage is what makes results survive after the current program ends. Classifying software by type matters because the operating system sits under everything else, applications do the tasks I actually want, and utilities look after the machine itself.

## 5. Difficulties faced
Deciding whether something like macOS counted as application software. I resolved it by asking who the software serves: it manages the computer itself, so it is operating system software, not an application.

## 6. How I resolved them
Used the definitions from the assignment: OS software manages the computer and its resources; application software helps users perform tasks; utility software maintains or protects the computer.
